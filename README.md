# Portafolio Web Personal 🚀

Portafolio profesional y responsivo con enfoque en accesibilidad, diseño moderno y código limpio.

## 🛠️ Tecnologías utilizadas
* **HTML5 Semántico:** Estructura clara (`<dl>`, `<dt>`, `<dd>`, atributos `aria-hidden`).
* **CSS3 Avanzado:** Diseño adaptable con CSS Grid, Flexbox, variables personalizadas y tipografía fluida mediante `clamp()`.
* **TypeScript:** Lógica tipada para la renderización dinámica de proyectos.
